🗄️ Maklumat Storan & Pangkalan Data
⚠️ Had Sistem: Sistem ini menyimpan data dalam localStorage pelayar sahaja. Data terhad kepada pelayar dan peranti berkenaan. Data akan hilang jika cache pelayar dibersihkan. Untuk penggunaan rasmi sekolah, gunakan backend pelayan dengan pangkalan data yang sebenar.
ℹ️ Kata laluan tidak disimpan dalam teks biasa. Sistem ini menggunakan demo-mode authentication. Untuk keselamatan penuh, laksanakan backend dengan JWT / session authentication.
